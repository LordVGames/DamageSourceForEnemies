# DamageSourceForEnemies
In vanilla the majority of enemy attacks don't have a DamageSource set, which means that items that rely on specific skill hits and mods that look for a skill's DamageSource will never work with most enemies. This mod fixes that by giving *every* enemy attack a proper DamageSource if it didn't have one already, based on the skill slot an attack is in.
